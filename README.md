# Part 1 - UMC Index Construction

Purpose: build Seoul district-level UMC scores for 2023 and 2024, plus report figures and tables used by later project parts.

## Current Pipeline

The active pipeline is Python-based. Older R scripts are preserved only under `scripts/_archived_R/`.

1. `scripts/preprocess_base_stations.py`
   - Builds `data/processed/base_station_by_district.csv`.
   - Reads base-station raw files under `data/raw/base_station/` and Seoul GIS files under `data/gis/Seoul/`.

2. `scripts/preprocess_living_pop.py`
   - Builds `data/processed/living_pop_by_district.csv`.
   - Reads monthly living-population ZIP files under `data/raw/생활인구/`.

3. `scripts/preprocess_telecom_traffic.py`
   - Builds `data/processed/telecom_by_district_2023.csv`, `data/processed/telecom_by_district_2024.csv`, and a combined file.
   - Reads telecom raw workbooks under `data/raw/`.

4. `scripts/calculate_umc_scores_v7.py`
   - Builds `output/tables/seoul_umc_scores_v7_2023.csv` and `output/tables/seoul_umc_scores_v7_2024.csv`.
   - Requires preprocessed files in `data/processed/` and selected raw inputs in `data/raw/`.

5. `scripts/visualize_umc_v7.py`
   - Builds year-specific figures under `output/figures/2023/` and `output/figures/2024/`.
   - Builds summary and descriptive tables under `output/tables/2023/` and `output/tables/2024/`.

6. `scripts/visualize_report.py`
   - Builds report-ready figures under `output/figures/report/`.

7. `scripts/03_affordability_eda.ipynb`
   - Exploratory analysis notebook for affordability.

## Data Management

- `data/raw/` is ignored by Git and treated as protected source data. Do not commit or overwrite raw data.
- `data/processed/` is generated by preprocessing scripts and is not currently committed.
- `data/gis/` contains tracked GIS support files used by the visualization pipeline.
- `output/tables/` and `output/figures/` contain tracked result artifacts used by downstream writing and reporting.
- Local editor or OS files such as `.DS_Store`, `.Rhistory`, `.Rproj.user/`, cache files, and logs should remain untracked.

## Reproducibility Notes

All active Python scripts resolve paths relative to this repository root:

```python
ROOT = Path(__file__).resolve().parents[1]
```

This avoids machine-specific paths such as `C:\woo\...`. If a script fails, first check whether required raw or processed inputs exist under the expected local folders before changing analysis logic.
